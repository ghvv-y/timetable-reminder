## 一、高优先级

### 1. ✓ 关掉短信开关无效，到点仍会发短信
- 位置：`lib/services/app_state.dart:453`
- 现象：调度 payload 里只传 `mode: settings.reminderMode`，而整个 `app_state.dart` 从未引用 `smsEnabled`（该字段只在 `lib/model/models.dart` 里定义与序列化）。
- 后果：用户关闭短信后，闹钟到点仍按含短信的模式注册并发送。
- 修法：同步前按 `smsEnabled` 把含短信的模式降级为仅通知；纯短信模式则停止注册。

### 2. ✓ 改课 / 导入课表 / 改作息，都没有重建提醒
- 位置：`lib/services/app_state.dart:152`（增改课程）、`:203`（识别导入）、`:210`（改作息）
- 现象：三处都只 `await syncAlarms()`，而该文件第 65-66 行注释明确写着「有课表时必须走 `regenerateCourseAlarms` 而不是 `syncAlarms`」，`regenerateCourseAlarms` 也确实存在。
- 后果：新课没有提醒；改课程时间或备注后仍按旧时刻旧内容发；改作息后下课提醒仍按旧时间。
- 修法：课程与作息齐全时统一走 `regenerateCourseAlarms()`，否则先清理失效的课程闹钟再同步。

### 3. ✓ 存储先删后改名，中途失败会丢全部数据
- 位置：`lib/services/storage.dart:230-231`
- 现象：`if (await f.exists()) await f.delete(); await tmp.rename(f.path);` —— 删除与改名之间没有任何兜底，启动时也不恢复遗留 tmp。
- 后果：进程被杀或改名失败，课表与闹钟数据全部丢失。
- 修法：同目录原子替换（先写 `.bak` 或直接用临时文件覆盖式替换），并在启动时恢复遗留 tmp。

### 4. ✓ 按星期闹钟不选任何星期也能保存
- 位置：`lib/pages/alarm_page.dart:523`
- 现象：`weekdays: weekdays.toList()` 直接写入，保存路径没有非空校验。
- 后果：闹钟显示已启用但永远匹配不到日期，用户到点收不到提醒。
- 修法：保存前校验 weekly 闹钟 `weekdays` 非空，为空则阻止并提示。

### 5. ✓ 结束节次可小于开始节次（两处）
- 位置：`lib/pages/ocr_page.dart:968`、`lib/pages/schedule_page.dart:838`
- 现象：`onChanged: (int? v) => setLocal(() => end = v ?? end)` 这类写法没有夹取，保存前也无区间校验。
- 后果：保存倒置区间，课表页算出负高度导致布局异常，对应提醒时刻也错。
- 修法：改结束节次时自动保证 `end >= start`（或反向夹取 start），保存前再校验一次。

### 6. 识别导入课程后只同步旧闹钟
- 位置：`lib/services/app_state.dart:203`（与第 2 条同源，单列因为后果不同）
- 后果：被替换掉的旧课程闹钟若来自自定义闹钟集合，仍会按旧内容触发。

### 7. URP 文本单空格切列失败
- 位置：`lib/ocr/paste_parser.dart:262`
- 现象：无制表符时只按「两个以上空格」切列，兼容不了制表符被转成单个空格的情况。
- 后果：精确的粘贴导入失败或退回不准确的通用解析。
- 修法：无制表符时按单个空白切列，并按 URP 固定列位置与 `>>` 边界提取课程名、教师。

### 8. 不连续周次被合并成整段
- 位置：`lib/ocr/table_parser.dart:716`
- 现象：周次解析只返回 `(lo, hi, type)` 三元组，「3-4,6-10周」会被当成 3-10 周连续。
- 后果：第 5 周等实际无课的周也会发课前与课后短信。
- 修法：按周次区间分别生成课程记录，保留多段区间而不是只留总起止。

### 9. 兜底节次编号按 OCR 顺序而非坐标
- 位置：`lib/ocr/table_parser.dart:360`
- 现象：无节次标签时按 OCR 返回顺序编号，没有按 `centerY` 排序。
- 后果：OCR 顺序与视觉顺序不一致时，作息时间绑到错误节次，短信在错误时刻发送。
- 修法：编号前先把 `timeOnly` 按 `centerY` 从上到下排序。

### 10. ✓ 两个跳过用例正好盖住真实缺陷
- 位置：`test/widget_test.dart:282`（时间拆两行未配对）、`:473`（缺「节」字漏解析一个节次）
- 现象：两处均为 `skip: '已知未完成…'`，注释也写明了原因。
- 后果：测试全绿但缺陷仍在，真实截图会漏解析作息与节次。
- 修法：补齐两种写法后取消 skip，并保留原有断言。
