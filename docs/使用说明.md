# 使用说明（给使用者）

## 一、安装

1. 把 `课表提醒-release.apk` 传到手机，点击安装（首次需允许安装未知来源应用）。
2. 打开 App，**首次启动会自动做权限检查**，缺哪项会列出来，可点「一键授予」。
3. 进入「设置」，填入你自己的手机号，点「发送测试短信」。
4. 手表如果弹出这条短信，说明整条链路已经打通。

> 设置页顶部有 **「权限自检」卡片**，随时可以重新检查四项状态：
> 发送短信、精确闹钟、通知、短信接收号码。

### vivo / 小米等机型的特别说明

部分机型**没有「闹钟和提醒」这个开关**（那是原生 Android 12+ 的入口），系统会默认放行，
自检里会显示「已授权」或「无需设置」，属正常。

但 vivo 上**必须手动打开「自启动」**，这个系统不提供查询接口：

```
设置 → 应用与权限 → 权限管理 → 自启动 → 课表提醒 → 允许
```

找不到就下滑搜索「自启动」。不开这一项，定时任务会被系统清理，闹钟不会触发。

## 二、录入课表（三种方式）

### 方式一：悬浮球截屏（推荐，截出来的图最清晰）

1. 识别页 → 打开「屏幕识别（悬浮球截屏）」开关
   - 首次会要两个权限：**显示在其他应用上层** 和 **截屏授权**
2. 切到课表页面（微信、教务系统、网页都行）
3. 点悬浮球「扫」→ 自动截取当前屏幕并识别
4. 回到本应用核对结果

> ⚠️ 系统规定截屏必须显示常驻通知与录制图标，所以**用完请把开关关掉**，
> 通知会立即消失。关掉后闹钟提醒依旧完全静默。

**如果悬浮球没出现**：识别页的屏幕识别卡片里有 **「查看启动日志」** 按钮，
点开能看到原生侧的每一步记录，把它截图发我即可定位问题。

### 方式二：识别截图

1. 底部切到「识别」页。
2. 点「选择截图」（或「拍照」）。
3. 等待识别完成，页面会显示识别到的节次时间与课程。
4. 核对无误后点「确认导入课表」。

**识别不理想时，先看「识别到的原始文字」这一栏**：

| 看到的情况 | 说明 |
| --- | --- |
| 原始文字为空 | 图片本身没被识别出文字，换清晰的正对截图 |
| 有文字但没有课程 | 认到字了，解析规则没匹配上，可手动录入 |

解析器会自动处理这些真实课表写法：

- 节次写成 `1-2节`、`3、4节`、`(3-4节)`、`第三节` 都能认
- 课程格子里**没写节次**时，按纵向位置投射到时间轴自动推断节次
- 星期由横向位置判断，不再只认文字里的「周X」
- 时间栏被 OCR 拆成上下两行（`08:00` / `08:45`）会自动配对成区间
- 连字符被认成 `-`、`—`、`~`、`至`、`到` 等都能解析

推断出来的结果会给出「请重点核对星期与节次」的提示。

### 方式三：手动补充

在「识别」页点「手动添加课程」，填课程名、星期、节次、地点。
识别不到时间栏时，点「套用默认模板」，再到设置页逐条改成你们学校的作息。

## 三、闹钟管理

「闹钟」页把所有提醒放在一起：

| 分组 | 说明 |
| --- | --- |
| 课表自动提醒 | 由课表生成的上下课提醒，删掉课程时会一起移除 |
| 自定义闹钟 | 你自己添加的，比如起床、交作业 |

### 底部两个按钮

| 按钮 | 作用 |
| --- | --- |
| **添加闹钟** | 随时新增自定义闹钟，填时间、备注、重复方式 |
| **批量删除** | 进入多选模式，勾选后一次性删除多条 |

批量删除模式下：顶部显示「已选 N 条」，可「全选 / 取消全选」，
底部红色按钮一次删除，右上角 × 退出。

### 单条操作

- **开关**：右侧开关启用 / 停用
- **编辑**：点整条闹钟即可修改时间、备注、重复方式
- **删除单条**：点右侧垃圾桶图标；删错了点右上角 **撤销** 恢复
- **长按**：快速进入多选模式并勾选这一条
- **立即发送**：编辑面板底部，用来测试短信是否真的能发出去
- **重新生成**：点右上角刷新，按课表重新生成上下课提醒

### 课表页的批量删除

课表页右上角有 **批量删除按钮**（带斜线的垃圾桶图标）：

1. 点它进入多选模式，课程格子上出现复选框
2. 点格子勾选（可跨星期一多选），或点「全选」
3. 点顶部蓝色条上的 **删除(N)** 确认

> 注意：删除的是**整门课程**（含它在所有周次的课），
> 同时会移除它对应的上下课提醒。此操作不可撤销。

### 备注就是短信内容

编辑闹钟时填的「备注」，会 **一字不改** 地作为短信正文发出去。

建议写清四件事：**课程名 + 时间 + 地点 + 要带的东西**，例如：

```
数据结构 10:00 教三301 带上实验报告
```

控制在 70 字以内，手表一屏就能看完。

## 四、到点会发生什么

```
到点 → 手机静默发出短信 → 手机收到短信 → 华为手表震动显示
```

**手机本身不会响铃、不会震动、不会弹任何通知**，这是刻意设计的：
提醒只落在手表上，不打扰你用手机。

> 唯一的例外是「屏幕识别」功能开启期间，系统会强制显示一条常驻通知——
> 这是 MediaProjection 的规定，关闭开关后立即消失。

## 五、常见问题

**Q：到点了但手机没收到短信？**
1. 打开设置页看「权限自检」，短信那一项是否是绿勾
2. 检查接收号码是否填写正确
3. 查看设置页的「短信发送记录」，失败会有红色标记

**Q：短信发出去了，手表没动静？**
1. 权限自检里「通知」那一项是否已授权
2. 华为运动健康 → 设备 → 消息通知 → 确保已打开并勾选「信息」
3. 确认手机与手表蓝牙已连接

**Q：提醒时间偏晚？**
1. 权限自检里「精确闹钟」是否已授权
2. vivo 上还要开「自启动」与「电池不受限制」
3. 设置页把提醒提前量改为 10 分钟

**Q：课表识别只认出一部分？**
1. 先展开「识别到的原始文字」，确认是不是所有文字都认出来了
2. 用悬浮球截屏代替拍照，图片更清晰、识别率更高
3. 剩下的手动补录即可

**Q：电脑上能用吗？**
能。电脑用来管理课表、编辑闹钟、导入导出备份；
电脑没有短信通道，到点只写日志不发送。
手机与电脑的数据可以通过「设置 → 导出备份文件」再「导入备份文件」保持一致。

## 六、手机与电脑同步课表

1. 手机：设置 → 导出备份文件 → 得到 `timetable_backup.json`
2. 把文件传到电脑
3. 电脑：设置 → 导入备份文件 → 选择该文件

反之亦然。
